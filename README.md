### 📌 Featured Projects

#### 🎫 TicketVault – Distributed Event Ticketing System
> *Microservices · Redis Lua · RabbitMQ · Docker · CI/CD*

- Designed 3 independent microservices (Inventory, Booking, Notification) each with its own PostgreSQL database
- Built atomic ticket reservations with **Redis Lua scripts** to prevent race conditions and double-booking
- Engineered a **TTL-based hold mechanism** with keyspace notifications – automatically releases unpaid tickets after 15 minutes
- Integrated **RabbitMQ** for asynchronous inter-service communication
- Containerized with **Docker Compose** and deployed on Render with **GitHub Actions CI/CD**

🔗 [View Repository](https://github.com/szaric13/event-ticket-system) · [Live Demo](https://your-demo-url.com)

#### 🦷 Dental Clinic Management System – Full-Stack Application
> *Spring Boot · React · JWT · Docker · JUnit*

- Built a 6‑module platform covering scheduling, authentication, reviews, notifications, doctor workflows, and patient/doctor dashboards

- Wrote **30+ unit & integration tests** (JUnit 5, Mockito) covering critical business logic
